**[GitHub Copilot 云智能体](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** 可在云端异步处理工作。你可以在 GitHub 上分配任务，云智能体会在后台探索存储库、进行更改并创建拉取请求，让你可以继续处理其他工作。

这些练习将先添加云智能体需要遵循的自定义指令，再分配 GitHub 议题并让它实现需求。你将审查并使用自定义智能体来调整其工作方式，在智能体仪表板中监控和引导会话，最后审查它创建的拉取请求并继续完善结果。

## 先决条件

参加本工作坊前，请确保具备以下条件：

- [ ] 拥有已启用 **Copilot Student、Pro、Pro+、Business 或 Enterprise** 计划的 GitHub 账户
- [ ] 已为账户或组织启用 Copilot 云智能体

> [!TIP]
> 没有付费计划？通过验证的学生可以通过 [GitHub Education][callout-student-plan-education] 免费使用 GitHub Copilot。**Copilot Student** 计划包含本工作坊所需的智能体、模型上下文协议（MCP）、代码审查和 Copilot CLI 功能，因此可以用它完成所有工作环境的练习。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> 除 Copilot Free 外，Copilot Student、Pro、Pro+、Business 和 Enterprise 均提供云智能体。对于 Copilot Business 或 Enterprise，管理员必须为组织启用该功能。

> [!NOTE]
> 本工作环境不涉及模型上下文协议（MCP）。若要了解如何将 MCP 服务器与 Copilot 配合使用，请参阅 [CLI 工作环境](../cli/)或 [VS Code 工作环境](../vscode/)。
