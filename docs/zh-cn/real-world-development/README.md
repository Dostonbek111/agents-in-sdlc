通过真实场景、完整应用和共享待办事项，探索 GitHub Copilot 在软件开发生命周期中的应用。你将迭代规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家以开发者为主题、为桌游提供众筹服务的虚构公司。团队的待办事项已作为 GitHub 议题创建，可供你着手处理，其中包括筛选和分页等功能开发，以及无障碍和编码规范等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合自己构建方式的环境。每个工作坊都有独立的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright 模型上下文协议（MCP）、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

运行并行智能体会话、切换会话模式、协作使用画布，并在桌面应用中管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。通过 Copilot Chat 智能体模式、模型上下文协议（MCP）服务器和自定义智能体，在编辑器中完成工作。
